## 2024-05-18 - Missing noreferrer in target="_blank" links\n**Vulnerability:** External links with `target="_blank"` in React components (scouter/HeroLockOn.jsx and scouter/RankInsignia.jsx) had `rel="noopener"` but lacked `noreferrer`, while links in vanilla JS template literals (js/app.js) lacked both. This can expose the referer header to external sites and potentially allow reverse tabnabbing attacks depending on browser support.\n**Learning:** When using `target="_blank"`, it is crucial to always include both `noopener` and `noreferrer` to ensure full protection against reverse tabnabbing and referer leakage, especially across different environments (React vs vanilla JS).\n**Prevention:** Ensure all external links utilizing `target="_blank"` must explicitly include `rel="noopener noreferrer"`.
